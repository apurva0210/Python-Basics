# Python Basics

## 1. What is Python?

Python is a high-level, interpreted, general-purpose programming language known for its simple syntax and readability. It was created by Guido van Rossum and first released in 1991.

Python is widely used in web development, data analytics, artificial intelligence, machine learning, automation, and scientific computing.

## 2. Features of Python

- **Easy to Learn:** Python has simple and readable syntax.
- **Interpreted Language:** Python code is executed by an interpreter.
- **High-Level Language:** It hides many low-level hardware details.
- **Object-Oriented:** It supports classes and objects.
- **Cross-Platform:** Python programs can run on Windows, Linux, and macOS.
- **Open Source:** Python is freely available to use and distribute.
- **Extensive Libraries:** It provides many built-in modules and external libraries.

## 3. Applications of Python

- Data Analytics and Data Science
- Artificial Intelligence and Machine Learning
- Web Development
- Automation and Scripting
- Scientific Computing
- Desktop Application Development
- Internet of Things (IoT)

## 4. First Python Program

The following program displays a message on the screen.

```python
print("Hello, World!")
```

**Output:**
```text
Hello, World!
```

The `print()` function is used to display text, values, and other output in Python.

## 5. Why Learn Python?

Python is a popular programming language because it is easy to understand, versatile, and supported by a large community. Learning Python provides a strong foundation for programming, data analytics, and machine learning.
